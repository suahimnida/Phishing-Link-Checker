# 피싱 사이트 분석기 한계 정리

> 근거: `evaluation/results/v2/summary.md`, `false_negatives.csv`, `false_positives.csv` (`scripts/evaluate_model.py --model v2`로 다시 만들 수 있음)
> 평가 세트: 피싱 2,000건(KISA 2023), 정상 409건, 학습 데이터와 도메인이 겹치지 않게 구성

## 1. 평가 수치 (ML v2, 60점 = 피싱 판정 기준)

| 구분 | 오탐률 (정상 → 피싱) | 미탐률 (피싱 → 놓침) | ROC-AUC |
| --- | --- | --- | --- |
| ML 단독 | 34.2% | 10.3% | 0.879 |
| ML 단독, 학습에 없던 도메인만 | 31.4% | 10.3% | 0.889 |
| 서비스 전체 (ML + 공식 도메인 허용 목록) | 2.0% | 10.3% | 0.978 |

- **서비스 전체 오탐률 2.0%는 낙관적인 값이다.** 정상 평가 세트의 81.2%가 허용 목록 도메인이어서 허용 목록이 대부분을 막아 준다. 허용 목록에 없는 처음 보는 정상 사이트는 ML 단독 수치(약 31~34%)를 기준으로 봐야 한다.
- 2026-10-12 수정: 모델에 넣기 전에 스킴·호스트를 소문자로 바꾸고 홈페이지 끝의 `/`를 지우도록 정규화했다(`canonical_url`). 이 수정으로 미탐률이 13.3% → 10.3%, ROC-AUC가 0.867 → 0.879로 좋아졌고 오탐률은 그대로다.

## 2. 미탐 (피싱인데 놓친 경우) — 205건

| 유형 | 건수 | 특징 |
| --- | --- | --- |
| 의심 특징이 거의 없는 짧은 도메인 | 202 (98.5%) | 의심 키워드 0개, 호스트 평균 15.5자, 대부분 경로 없음, 전부 KISA 2023 한국 대상 피싱 |
| 기타 | 3 | |

대표 사례: `http://www.makevusim.com/K5aGac` (6.97점), `http://www.spellmanh.com/?` (7.42점), `http://www.artbooksk.com/Nv5Grx` (8.27점)

- **원인**: 한국 대상 스미싱 사이트는 `login`, `verify` 같은 단어 없이 의미 없는 짧은 영문 도메인을 쓰는 경우가 많다. URL 문자열에 피싱 단서가 없으므로 문자 패턴 모델로는 구분하기 어렵다.
- **대응**: 이런 사이트는 블랙리스트(KISA)와 평판 신호(도메인 등록일, 인증서 첫 발급일)가 더 효과적이다. 평판 신호는 현재 점수에 반영하지 않고 참고 근거로만 보여 준다(향후 과제).
- **사용자 안내**: 리포트 한계 항목에 "판정이 '정상'이어도 문자로 받은 링크라면 공식 경로로 확인"을 넣었다.

## 3. 오탐 (정상인데 피싱으로 판정) — 140건

| 유형 | 건수 | 대표 사례 |
| --- | --- | --- |
| 정상 홈페이지인데 `https://www.` 형태가 아님 | 85 | `paypal.com`, `http://paypal.com` (98점대) |
| 경로가 있는 정상 URL | 22 | |
| 기타 정상 | 19 | |
| 정상 서비스의 로그인·계정 경로 (의심 키워드 포함) | 14 | `login.coupang.com/login/...`, `accounts.kakao.com/login/...` (99점대) |

- **원인**: 피싱 사이트가 흉내 내는 대상이 바로 이런 정상 로그인 페이지라서, URL 문자열만으로는 진짜와 가짜가 거의 같아 보인다. 또 원래 학습 데이터(PhiUSIIL)의 정상 URL이 `https://www.` 형태 위주였던 편향이 v2에서도 일부 남아 있다.
- **대응**: 공식 도메인 허용 목록(약 500개)으로 주요 서비스의 오탐을 막는다. 허용 목록에 없는 사이트는 오탐이 남는다.

## 4. 기능별 한계

| 기능 | 한계 |
| --- | --- |
| 블랙리스트 | 2024년 KISA 공개 목록 기준이라 이후 새로 생긴 피싱 사이트는 없다. 원본의 도메인 형식이 아닌 값(`kca`, `club`, 전화번호 등)은 서버가 읽을 때 걸러 낸다. |
| 단축 URL | 실제 목적지를 알 수 없어 URL 문자열과 관계없이 '피싱 의심'(30~59점)으로 표시한다. KISA 목록과 URL이 정확히 일치하는 단축 링크만 피싱으로 확정한다. 단축 링크를 펼쳐 목적지를 확인하는 기능은 사이트에 접속해야 하므로 넣지 않았다. |
| 표기 차이 | http/https, 대소문자, 끝의 `/` 차이는 정규화로 대부분 몇 점 이내로 맞췄다. 다만 스킴 없이 도메인만 쓴 경우(`myshop.kr`)는 같은 주소의 `https://` 형태보다 점수가 15~20점 높게 나올 수 있다. 스킴을 붙여 넣는 정규화도 시험했지만 평가 결과가 거의 같아(오탐 −1%p, 미탐 +0.3%p) 적용하지 않았다. |
| 동형 문자 도메인 | 키릴·그리스 문자 등 자주 쓰이는 비슷한 글자 목록으로만 공식 도메인 흉내를 판단한다. 목록에 없는 글자를 쓰면 놓칠 수 있다. |
| 유사 사례 검색 | v2 학습 데이터에서 피싱·정상 2,500건씩 뽑아 다시 만들었지만, URL 특징 21개 기준이라 정상 URL도 피싱 사례와 가깝게 나올 수 있다 (평가 세트 정상 입력의 약 46%). 판정에는 쓰지 않으며, 공식 도메인 결과에서는 근거로 쓰지 않는다. |
| AI 설명 | 출처 번호, 주소·전화번호, 근거에 없는 숫자는 코드로 검사하지만, 숫자가 없는 거짓 문장까지 막지는 못한다. 검사에 걸리면 템플릿 설명으로 대신한다. |
| 본인 확인 잠금 | 실패 기록이 서버 메모리에만 있어 재시작하면 초기화되고, 다른 사람이 일부러 틀려 주인을 15분 동안 잠글 수 있다. |
